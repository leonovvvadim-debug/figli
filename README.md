# B. Счастье

Репозиторий для решения конкурсной задачи «B. Счастье».

## Структура

- `statement.txt` — исходное условие задачи.
- `solutions/` — отдельные файлы решений для тест-кейсов; шаблоны будут добавлены после получения исходных материалов конкурса.

## Задача

Составить допустимое расписание выкаток обновлений моделей на устройства, максимизирующее суммарное взвешенное пользовательское счастье при ограничениях на даты релизов, дневной лимит сервера, лимиты домашних сетей и число обновлений на устройство.
